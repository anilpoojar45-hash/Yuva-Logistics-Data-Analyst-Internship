# Yuva-Logistics-Data-Analyst-Internship
Data analytics project on last-mile delivery performance optimization for an e-commerce logistics provider — covers KPI definition, data cleaning, EDA, and predictive modeling in Python.
This repository documents a four-week logistics data analytics project focused on improving last-mile delivery performance for a mid-sized e-commerce logistics provider operating across Indian metro and tier-2 cities. The project addresses three core challenges — delivery delays during peak demand, rising per-shipment costs from inefficient routing, and inconsistent fulfillment times across city zones — by tracking three KPIs: On-Time Delivery Rate, Average Delivery Cost per Shipment, and Order Fulfillment Cycle Time. Work progresses through strategic planning, data collection and preprocessing, exploratory data analysis and visualization, and predictive modeling with optimization recommendations, using sujalsuthar/amazon-delivery-dataset on kaggle. Each stage's code and findings are added weekly as the project builds toward a full predictive model for delivery-time forecasting and route optimization.
## Project Structure
- week1/ — Strategic planning: scenario, KPIs, roadmap, pseudocode
- week2/ — Data collection, cleaning, and preprocessing
- week3/ — Exploratory data analysis and visualizations
- week4/ — Predictive modeling and optimization recommendations
